## Огляд

KBM Logic v3.1 - це комплексна система управління проєктами, що поєднує Kanban-дошку, фінансовий аналіз на основі EVM та систему управління ризиками. Система автоматично розраховує ключові фінансові метрики (PV, AC, EV, BAC) з урахуванням робочого розкладу проєкту та історичних ставок ролей.

### Ключові Особливості v3.1

- ✅ **Budget at Completion (BAC)** - Нова метрика, що відображає загальний бюджет проєкту
- ✅ **Recalculate Financial Data** - Функція перерахунку історичних снапшотів
- ✅ **S-Curve Carry Forward** - Візуальна логіка, що запобігає "drop to zero" глітчам
- ✅ **Salary-Driven Task Estimation** - Генерація ідеальних демо-проєктів через `seed-ideal-project.js`
- ✅ **Role-Based Compensation** - Зарплати прикріплені до ролей, а не користувачів

## Швидкий Старт

1. **Встановлення:**
   ```bash
   npm run install:all
   ```

2. **Конфігурація:**
   - Створіть `server/.env` з MongoDB URI та Firebase credentials
   - Створіть `client/.env` з Firebase конфігурацією

3. **Запуск:**
   ```bash
   npm run dev
   ```

4. **Генерація Демо-Даних:**
   ```bash
   node server/scripts/seed-ideal-project.js
   ```

Детальні інструкції: [Архітектура та Налаштування](./01-architecture-and-setup.md)

## Основні Зміни в v3.1

### Нові Функції

1. **Budget at Completion (BAC)**
   - Нова метрика, що показує загальний бюджет проєкту
   - Відображається як окрема картка на Фінансовому Dashboard
   - Використовується для розрахунку "Remaining Work Budget" (BAC - AC)

2. **Recalculate Financial Data**
   - Кнопка в Налаштуваннях → Danger Zone
   - Видаляє та регенерує всі історичні снапшоти
   - Використовується після зміни історичних ставок або оцінок

3. **S-Curve Carry Forward**
   - Візуальна логіка, що запобігає падінню ліній AC/EV до 0
   - Використовує останнє відоме значення, якщо снапшот відсутній
   - Забезпечує плавність графіка

### Покращення

- Покращена документація фінансових розрахунків
- Додано скрипт `seed-ideal-project.js` для генерації ідеальних демо-проєктів
- Уточнено модель компенсації (ролі vs користувачі)
- Додано валідацію обов'язкових полів у схемі бази даних
